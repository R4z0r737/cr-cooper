# AČR Cooper

Instalovatelná webová aplikace pro Cooperův test. Data se ukládají pouze lokálně v prohlížeči uživatele.

## Lokální spuštění

```bash
npm install
npm run dev
```

## Nasazení

V GitHub Pages nastavte Source na **GitHub Actions**. Každý push do větve `main` aplikaci automaticky sestaví a nasadí.
